# Fun mode design

Approved by the user: retain Standard as the default; add a friendly illustrated
walkie-talkie with an 8-bit green monitor, state-specific emotions and contained
motion. Show only during activity and brief result feedback. No persistent idle pet.

Fun uses the same nonactivating, mouse-transparent overlay lifecycle and latest-only
audio level as Standard. Its compact 260 × 200 point footprint includes the antenna,
hands and feet. A fixed screen has separate status, face, waveform and hint rows.
The gold body stays anchored; antenna wiggles and pixel facial expressions communicate
listening, concentrating, thinking, happiness, helpful concern and cancellation.
Audio silence stays flat. Reduce Motion freezes decorative movement and waveform.

Store Appearance = Standard/Fun in existing preferences. Preview can compare styles
without changing the saved setting or opening the microphone. Preview reuses one
controller per app, including onboarding, to prevent competing overlays. Idle stays
hidden; success feedback ends on the existing timer. Keep native status text for
accessibility and preserve full original messages in the menu.

Artwork is native vector/layer geometry rather than generated bitmap sprites: this
supports a crisp live monitor, small independent motions and no new runtime packages.
